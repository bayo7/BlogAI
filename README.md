# 🤖 ASP.NET Core ile API Tabanlı Yapay Zeka Atölyesi

## 📋 Proje Hakkında

Bu proje kapsamında ASP.NET Core kullanılarak modern ve ölçeklenebilir RESTful API geliştirme süreçleri ele alınmaktadır. Çok katmanlı (N-Layer) mimari yaklaşımı uygulamalı olarak incelenirken; OpenAI, Google Gemini, Anthropic Claude ve Microsoft Azure AI gibi yapay zeka servislerinin API entegrasyonları gerçekleştirilmektedir. Metin analizi, özetleme, duygu analizi, soru-cevap sistemleri ve otomatik içerik üretimi gibi yapay zeka uygulamalarının yanı sıra speech-to-text, text-to-speech ve text-to-image senaryoları da ele alınmaktadır.

---

## 🛠️ Kazanımlar

- ASP.NET Core üzerinde API tabanlı yapay zeka uygulamaları geliştirme
- Hugging Face, OpenAI, Gemini, Microsoft Azure, Claude, Replicate vb. servislerle entegrasyon
- LLM'ler ile çalışan web ajanları oluşturma
- Gerçek zamanlı veri işleyen akıllı web arayüzleri geliştirme
